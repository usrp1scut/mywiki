上周的主线是“用什么把 Agent 跑起来”。本周榜单给了一个更具体的答案：**让 Agent 去读那些没有源码的东西。**

第一名 [morluto/rea](https://github.com/morluto/rea) 一周涨了近 24 万星，做的事只有一句话——把逆向工程工具包成 MCP，让 Claude Code、Codex、Cursor、Gemini CLI 去拆原生二进制、Electron 应用、APK、固件和网站。同一股力量把 [Ghidra](https://github.com/NationalSecurityAgency/ghidra) 和 [AnyPS5](https://github.com/boykopovar/AnyPS5) 一起带上榜：这周的热榜第一次出现了“逆向工程三件套”。

另一条主线更安静但更值得记：**“净室重写”被做成了一条生产线。** ArtCraft 本周开源并涨了 1.8 万星，它背后是十几个 9 月底到 10 月初密集创建的纯 Rust 仓库——PhotoCraft、FilmCraft、PdfCraft、WordCraft、GridCraft……全部对标 Adobe 与 Office。

> 说明：本文依据 [GitHub Trending weekly](https://github.com/trending?since=weekly) 于 2026 年 10 月 18 日抓取的公开页面，并结合各仓库 README、GitHub REST API 元数据与公开报道整理。本次页面解析出 **10 个**热门仓库；“本周新增 stars”与“总 stars”取自抓取时页面可见数据。Trending 反映短期关注度，不等同于长期采用率；本周头部项目的星数带有明显的传播放大效应，下文会单独讨论。“为什么变热”是结合项目定位、周增量与近期活跃度所作的审慎判断。

## 本周总览

先说结论：

- **Agent 的能力边界从“写代码”移到了“读没有源码的东西”。** REA 把 Hopper、Ghidra、IDA、JADX、binwalk、tshark 这些老工具统一挂在 MCP 后面，Agent 负责提问、追踪和归纳。它最值得学的不是工具数量，而是**证据分级**：每条结论都标成“看到的 / 推断的 / 不知道的”。
- **“重写一个 Photoshop”从玩笑变成了流水线。** ArtCraft 与其同门仓库在两周内密集开源，全部纯 Rust、MIT 或 Apache-2.0、clean-room。AI 让“重写商业软件”的边际成本低到可以批量复制，这才是本周真正的结构性变化。
- **上下文管理分成两条技术路线。** context-mode 在本机把工具输出关进沙箱（号称 98% 削减），billion-context 在 Agent 与模型 API 之间做可逆的分层压缩。一个管“进来的数据”，一个管“已经装进去的对话”。
- **插件市场开始处理包管理的老问题。** Anthropic 官方插件目录明确规定 `name` 是不可变 slug，改名要走 `renames` 映射自动迁移；技能仓库则在 README 里声明“官方构建只来自本仓库”。供应链安全从口号变成了字段设计。
- **可控性重新压过提示词。** ArtCraft 用图层、3D 场景和角色姿态控制生成，hyperframes 用 HTML 当中间表示，diagram-design 直接输出可 diff 的 SVG。三家都在把“提示词”降级为流程中的一环。
- **非 AI 侧只剩两个，而且都贴着二进制。** AnyPS5 做可执行文件重链接，Ghidra 做反汇编。严格与 AI 无关的项目本周只有 2 个，是近期最少的一周。

## AI 热门项目

### 1. [morluto/rea](https://github.com/morluto/rea)

- **它是做什么的**：一个逆向工程的 MCP 服务器。装上之后，Agent 可以检查原生二进制（伪代码、汇编、符号、调用与引用）、Go/Rust 二进制（内嵌的编译器版本、模块、依赖边）、WASM、EVM 字节码、SQLite、.NET 程序集、Android APK 与设备、Flutter 应用、固件、pcap 抓包、逻辑分析仪记录，以及 JavaScript/Electron 应用和网站。用法就一句 `npx rea-agents setup`，它会写入 MCP 配置和配套的工作流说明。
- **为什么这周会热**：本周新增约 **23.99 万** stars，总 stars 约 **30.95 万**，是全榜第一，也是近期单周涨幅的极值。仓库 2026 年 4 月创建，也就是说绝大部分星是这一周内来的。十月中旬 YouTube、Instagram 上出现了一批“用 REA 复刻 Obsidian 搜索 / Notion 剪贴板桥”的演示视频，传播路径非常典型：先有可复现的惊艳 demo，再有人群涌入。
- **有什么新意**：它没有自己实现反汇编器，而是把 Hopper、Ghidra、IDA、Kuna 反编译器、objdump、Rizin、JADX、binwalk/unblob、tshark、sigrok 统一成受控 provider，缺哪个就让你自己装哪个，它只负责编排和取证。真正的设计重点是**结论必须带证据**：每条发现都标注是实际看到的、推断的，还是未知的，并附上限制条件。这一条比“支持 20 种目标格式”重要得多——逆向工程最怕的就是模型把猜测说得像事实。另外 README 顶部特意放了一段警告：仓库名相似、README 被抄并不代表是官方版本，请只从 `morluto/rea`、`rea.tools` 或 npm 安装。**一个项目开始提醒用户防仿冒，说明它已经进入了会被仿冒的阶段。**

### 2. [storytold/artcraft](https://github.com/storytold/artcraft)

- **它是做什么的**：一个面向图像与视频生成的桌面 IDE，Windows/macOS 有稳定版，Linux 可自行构建。核心思路是把“提示词”变成“搭场景”：2D 图层合成、3D 场景布置、角色摆姿、身份迁移、图生 3D 网格、背景分离，然后在这些约束下调用模型出图或出视频。MIT 或 Apache-2.0 双许可，纯 Rust。
- **为什么这周会热**：本周新增约 **1.85 万** stars，总 stars 约 **3.19 万**。仓库其实 2022 年就存在，但十月中旬才正式开源，随即在社交平台上扩散。它不是孤立事件：同一组织在 9 月 30 日到 10 月 9 日之间集中放出了一整批仓库——PhotoCraft（约 6.65 万星）、PdfCraft（约 1.55 万）、FilmCraft（约 1.46 万）、WordCraft（约 1.41 万）、LightCraft、VectorCraft、EffectCraft、GridCraft、CADCraft、SoundCraft……全部是“纯 Rust、clean-room、对标某个商业软件”的同一套模板。
- **有什么新意**：它把“模型目录”本身做成了产品功能。README 里列了 **62 个模型**：图像 16 个（Nano Banana、GPT Image、FLUX、Seedream 各系列）、视频 25 个（Seedance、Kling、Veo、Sora、Vidu、MiniMax、Flux 3）、音乐与音效 5 个（Suno、Seed Audio）、3D 网格 11 个（混元 3D、Tripo3D、Meshy、Rodin）、世界与高斯泼溅 5 个（Marble、TripoSplat），再叠加 Grok、Midjourney、Sora、World Labs 几家外部 provider。对创作者来说，这意味着“换模型”不再是换工具，而是换下拉框。**当一个开源项目开始维护 62 个模型的兼容矩阵，它竞争的其实是工作流入口，不是模型能力。**

### 3. [mattpocock/skills](https://github.com/mattpocock/skills)

- **它是做什么的**：一位工程师日常在用的 agent skills 集合，定位是“为真正做工程的人写的技能”，直接从作者的 `.agents` 目录同步出来。
- **为什么这周会热**：本周新增约 **1.13 万** stars，总 stars 约 **29.52 万**，是全榜总量第二大的仓库。上周它也在榜上（当时约 9,179 周增），本周不降反升。
- **有什么新意**：延续上周的判断，它的价值不在“技能多”，而在“技能小”。每个技能都可读、可改、可组合，明确不接管流程，把编排权留给使用者。分发上同时提供 Claude、Codex、Copilot 的插件市场、Gemini CLI 与通用 `npx skills` 五条通道，并提醒不要重复安装。本周它继续增长这件事本身说明：**在“技能”这件事上，个人工程品味仍然打得过团队打包的方案。**

### 4. [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)

- **它是做什么的**：一个画图的 agent skill。45 种图型（架构图、象限图、时序图、流程图等），输出是**单个自包含的 HTML + SVG 文件**，双击就能看，可以导出 PNG/SVG，也能导入 draw.io、Mermaid、Excalidraw 的既有图。
- **为什么这周会热**：本周新增约 **8,382** stars，总 stars 约 **5.71 万**。它踩中了一个很具体的痛点：Agent 默认生成的图（尤其是 Mermaid 默认主题）能表达结构，但拿不进正式文档。README 的口号写得很直白——"No shadows. No Mermaid slop."
- **有什么新意**：它把“品牌一致性”做成了 onboarding 步骤：给它一个网址，它会抓取配色与字体，之后所有图都按这套视觉规则生成；也可以先给一句“给我画个架构图”，它自己选图型、先讲计划、再产出文件。安装走 `npx skills add cathrynlavery/diagram-design` 或 Claude 插件市场双通道，并声明官方构建只来自该仓库。**对长期用 Mermaid 写文档的团队来说，这是一个明确的替代选项：牺牲“文本可 diff”，换取“出版级视觉”。**

### 5. [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)

- **它是做什么的**：把 HTML、CSS、媒体和可 seek 的动画渲染成确定性 MP4 的开源框架。既能当本地 CLI，也能作为技能给 coding agent 用，还能当托管创作产品的渲染内核。
- **为什么这周会热**：本周新增约 **5,639** stars，总 stars 约 **6.61 万**。它上周也在榜（约 3,996 周增），增速反而在加快。
- **有什么新意**：它坚持 HTML 作为中间表示——可读、可 diff、可 lint、可 seek、可预览，最后一次性渲染成 MP4。21 个技能里有一个 `/hyperframes` 路由器，负责为任意一句“帮我做个……”挑工作流，其余技能按需安装。和 ArtCraft 放在一起看很有意思：**一个用图层和 3D 场景约束生成，一个用 HTML 约束生成，路径不同，但都在反对“抽卡式提示词”。**

### 6. [mksglu/context-mode](https://github.com/mksglu/context-mode)

- **它是做什么的**：一个专门治“工具输出把上下文撑爆”的 MCP 服务器。它把工具调用放进沙箱执行，只把结果摘要送回上下文（README 举例：315 KB 变成 5.4 KB，约 98% 削减）；把每次文件修改、git 操作、任务、错误和用户决策记进 SQLite，压缩后用 FTS5 + BM25 检索回相关片段，而不是把整段历史倒回去。
- **为什么这周会热**：本周新增约 **4,438** stars，总 stars 约 **3.05 万**。README 标注它上过 Hacker News 首页（570+ 点），这类“省 token、救长会话”的工具在 HN 上一直有稳定受众。
- **有什么新意**：它提出了一条有点反直觉的原则——**“让模型写代码去分析，而不是把数据读进上下文”**：与其读 50 个文件数函数，不如让 Agent 写个脚本 `console.log` 出结果。它把这条做成跨 17 个客户端的强制路由（靠 hooks 注入），并明确不规定模型该怎么说话，理由是过度的“简洁提示词”会拉低编码与推理表现。需要注意许可证是 **ELv2**，不是标准开源许可；README 里那面公司 logo 墙属于自我声明，未经独立验证。

### 7. [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official)

- **它是做什么的**：Anthropic 官方维护的 Claude Code 插件目录，分 `/plugins`（官方自研）与 `/external_plugins`（合作方与社区），通过 `/plugin install {name}@claude-plugins-official` 安装。
- **为什么这周会热**：本周新增约 **3,581** stars，总 stars 约 **4.19 万**。当插件数量多到需要“发现”而不是“搜索”时，官方目录自然成为入口。
- **有什么新意**：它的规则写得像包管理器规范，而不是营销页。`name` 是**不可变 slug**，一旦发布就不能改，改标签只能动 `displayName`，真要改名必须写进顶层 `renames` 映射让老用户自动迁移；没有 `plugin.json` 的技能仓库可以用 `strict: false` 加显式 `skills` 数组直接挂进市场。README 开头还有一段少见的安全声明：Anthropic 不控制插件里包含的 MCP 服务器和文件，也无法验证它们以后不会变，装之前请自行判断。**插件生态走到第二年，终于开始补“命名空间”和“信任边界”这两门必修课。**

### 8. [ranxianglei/billion-context](https://github.com/ranxianglei/billion-context)

- **它是做什么的**：一个夹在 Agent 与模型 API 之间的代理，重写 Anthropic/OpenAI 的流式响应，把已经消费掉的对话增量地压成分层摘要。目标很直白：100K 窗口够用、token 省 5 倍、单会话跑上几个月（累计几十亿 token）。
- **为什么这周会热**：本周新增约 **888** stars，总 stars 约 **1,751**。绝对值很小，但它是**连续第二周在榜**（上周约 659），属于慢热型项目——这类工具通常靠“用了一个月没崩”的口碑传播，而不是靠 demo 视频。
- **有什么新意**：它强调压缩是**增量、可逆、对 prefix cache 友好**的：摘要按小段写入，可以按需解压，缓存前缀不被破坏（README 声称健康会话的缓存命中率在 95–97%）。项目还带了一篇开源论文，给出 4.5 个月、3 台机器、174,327 次模型调用、187.6 亿输入 token 的生产数据，在 204,800 token 的模型上零窗口越界，最长会话 8,584–12,049 次调用。支持的宿主列表里包含 Hermes。**在一个满是“理论上能省 token”的品类里，敢公开长周期调用数据的很少。**

## 非 AI / 泛基础设施

严格与 AI 无关的项目本周只有 2 个。数量虽少，但都集中在“二进制层面”，和上面的 Agent 逆向工程是同一枚硬币的两面。

### 1. [boykopovar/AnyPS5](https://github.com/boykopovar/AnyPS5)

- **它是做什么的**：把 PS5 可执行文件自动移植到 Linux 与 Windows 的工具。核心是一个**重链接器**：把可执行文件转换成目标系统的原生格式，再提供一套可在动态链接时使用的系统 prx 库实现。没有模拟器，也没有独立的运行时进程。GPLv2。
- **为什么这周会热**：本周新增约 **1.63 万** stars，总 stars 约 **4.19 万**。上周它是全榜第一（周增约 2.5 万），本周回落到第三，但仍在榜——热度在退潮，项目本身在推进。
- **有什么新意**：这周新增的信息量在工程侧而非概念侧。着色器重编译器已经能产出 SPIR-V，编译时可选接 Spirv-Tools 做校验；多了一个纯浏览器端的转换器（文件不出本机）；输入映射支持 SDL 手柄和 `anyps5-input.ini` 键鼠配置；社区另做了一个按游戏追踪进度与阻塞点的 blocker map。项目对失败的处理也很硬：遇到不支持的状态直接抛 `std::runtime_error` 并终止，不做静默降级。**“宁可崩，也不假装能跑”这种取舍，恰恰是兼容层项目最难得的自律。**

### 2. [NationalSecurityAgency/ghidra](https://github.com/NationalSecurityAgency/ghidra)

- **它是做什么的**：NSA 开源的软件逆向工程框架，Java 编写，反汇编、反编译、脚本化分析一应俱全，是这个领域事实上的公共基础设施。
- **为什么这周会热**：本周新增约 **7,608** stars，总 stars 约 **9.04 万**。需要说明的是，**这次不是版本事件**：最新发布 12.1.4 是 9 月 21 日，本周没有新版本。真正的推力来自上下文——REA 把 Ghidra 列为首选 provider 之一，AnyPS5 这类项目又在大量讨论二进制层面的工作，一批新用户顺着工具链找了过来。
- **有什么新意**：Ghidra 本身这周没有新东西，它的意义在于**被重新发现**。当一个二十年级别的逆向工具因为“Agent 需要它”而重回热榜，说明这一波 AI 工具真正的瓶颈不在模型，而在模型够不够得着那些沉淀了二十年的专业工具。

#### 为什么非 AI 项目这么少

本周两个非 AI 项目都和二进制打交道，其余八个全部与 Agent 工具链相关。这不是分类偏好问题：Trending weekly 页面本周只渲染出 10 个仓库，其中 8 个明确服务于 AI 工作流，剩下 2 个又恰好被 AI 工作流带热。**当“给 Agent 造工具”成为涨星最快的品类，纯基础设施项目想上榜，要么足够底层（二进制、编译器），要么足够反叛（不做模拟器）。**

## 技术趋势分析

**一、Agent 的下一块地盘是“没有源码的软件”。** 上周的热榜在解决“怎么把 Agent 跑起来”，这周直接跳到“让它去读别人的程序”。REA 的产品形态值得注意：它不是又一个聊天界面，而是一层把专业工具接进 Agent 的适配层，并且用证据分级约束模型的表达。这条路如果走通，受影响最大的不是开发者工具，而是兼容性、迁移、安全审计这些长期靠人力堆的领域。

**二、净室重写正在被工业化。** ArtCraft 一家在两周内铺出十几个对标商业软件的纯 Rust 仓库，星数从几千到六万多不等。这些项目共享同一套叙事：clean-room、纯 Rust、MIT/Apache、AI 辅助编写。技术上它们大多还在早期（PhotoCraft 6.6 万星但功能完整度未知），但**“重写一个商业软件”的心理门槛已经被打穿了**。接下来真正稀缺的不是代码，而是测试集、兼容性验证和长期维护的人。

**三、上下文管理分成“入口”和“通道”两层。** context-mode 守在工具调用这一端，把原始数据挡在窗口之外；billion-context 守在 API 这一端，把已经进去的对话压小。两者都默认了一个前提：**窗口不会大到够用，压缩必须变成常驻机制而不是应急手段。** 区别在于前者改变 Agent 的行为（要求它写代码而不是读数据），后者对 Agent 完全透明。

**四、技能与插件的竞争从“格式”转向“分发与治理”。** 本周三个项目分别处在不同阶段：mattpocock/skills 靠个人品味和五通道分发，diagram-design 靠单一强场景（出版级图表）加品牌 onboarding，claude-plugins-official 则直接给出命名空间规则和迁移机制。共同点是都开始写“什么算官方”“改名怎么办”“装重了会怎样”。**一个生态成熟的标志，是它的 README 里开始出现约束条款。**

**五、生成式创作正在把“中间表示”捡回来。** ArtCraft 用图层和 3D 场景，hyperframes 用 HTML，diagram-design 用 SVG。三者都在做同一件事：把不可控的模型调用夹在可控的结构之间。这大概是过去一年“提示词工程”退潮后最健康的一次反弹——**不是让模型更听话，而是让模型只负责它擅长的那一段。**

**六、星数通胀需要打折看。** REA 一周 24 万星、skills 总量 29.5 万星、ArtCraft 单周 1.8 万星，这些数字背后是短视频与社交平台的放大效应。它们证明“注意力到了”，不证明“采用率到了”。判断一个项目是否真的在改变工作方式，更可靠的指标是：issue 区的提问质量、是否有第三方集成、以及三个月后还在不在更新。

## 本周最值得关注的新鲜点

- **REA 的“证据分级”**：把“看到的 / 推断的 / 不知道的”做成输出的一等字段。这个模式应该被更多 Agent 工具抄走——尤其在安全、审计、逆向这些“说错话代价很高”的场景。
- **billion-context 的生产数据**：4.5 个月、17.4 万次调用、187.6 亿输入 token、零窗口越界。在一个靠感觉宣传的品类里，这种长周期自证很少见，也很容易被证伪，所以更有参考价值。
- **claude-plugins 的 `name` 不可变 + `renames` 自动迁移**：npm 花了十年才把包名与迁移讲清楚，插件市场一上来就照抄了正确答案。
- **diagram-design 的“反 Mermaid”立场**：它没有说 Mermaid 不好，只是把“能进正式文档”当成硬指标。对天天在 Markdown 里画架构图的人来说，这是一个很实际的提醒。
- **ArtCraft 的 62 模型目录**：当模型数量超过一定阈值，“支持哪些模型”就从特性列表变成了护城河——用户不想为了换个模型而换一套工作流。
- **AnyPS5 的“崩给你看”**：遇到不支持的状态直接抛异常退出，不静默降级。兼容层项目最常见的死法就是“看起来能跑”，它选择了相反的路。

## 结语

这一周的热榜讲了一个很清楚的因果：**当模型足够会读代码，下一步必然是去读没有代码的东西；当重写软件的成本足够低，下一步必然是把重写做成流水线。**

REA 和那十几个 Craft 仓库，看似一个在拆别人的程序、一个在重建别人的程序，其实是同一种能力的两种用法。真正决定它们能走多远的，不是涨了多少星，而是有没有人愿意为“读得准”和“跑得稳”持续投入——逆向工程要的是证据链，净室重写要的是测试集。这两件事都没有捷径，也都不适合用周榜来衡量。
