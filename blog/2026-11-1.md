上周的榜单在回答“Agent 干完活之后，凭什么让人相信它干对了”。本周换了一个问题：**干对了，为什么看起来还是像机器做的？**

[Hallmark](https://github.com/Nutlope/hallmark) 一周涨 1.2 万星，给出的答案不是更会画，而是更会拒绝：一套三级 gate，加一个每次都从全新上下文进入的评审员。同一周里，Impeccable、Taste Skill、jakubkrehel/skills、Claude SEO 一起挤进榜单——**五个“反 AI slop”项目合计 35,154 星，占全榜周增的 39.8%**。另一半注意力则流向出处：谁写的、能不能装、收不收费。

> 说明：本文依据 [GitHub Trending weekly](https://github.com/trending?since=weekly) 于 2026 年 11 月 1 日抓取的公开页面，结合各仓库 README、GitHub REST API 元数据与最新 release 记录整理。本次页面解析出 **15 个**热门仓库；“本周新增 stars”取自 Trending 页面，“总 stars / fork / 未关闭 issue / 创建时间 / 许可证”取自 API 抓取时刻。需要说明一点：同一天不同时刻抓取 Trending，返回的组合与排序会变化（本次两次抓取得到过不同名单），因此本文只对这一次快照负责。Trending 反映短期关注度，不等同于长期采用率；“为什么变热”是结合项目定位、周增量、提交与发布节奏所做的判断，不是平台给出的归因。

## 本周总览

先说结论：

- **设计的“AI 味”第一次被写成了可执行的门槛。** Hallmark 12,062、Impeccable 12,031，分列本周周增第一与第二。它们卖的不是主题，而是“拒绝”：对比度、焦点态、reduced motion、编造事实——这些是永不发布的 Floor；而“每个标题上都挂一个眉标”“标题里有一个彩色词”这类模型默认审美，被写成可以按记录推翻的 Reflex。
- **判断力正在从模型手里被拿走。** Impeccable 的 62 条规则是确定性检查，零 LLM、零 API key；Hallmark 的最后一道关是全新上下文的评审员。这和上周 Cloudflare「发现者不能验证自己的发现」是同一个动作，只是从安全挪到了设计。
- **技能生态开始自我防卫。** ECC 在 29.4 万星的首页第一屏写“只从官方渠道安装，第三方镜像可能含恶意软件”；dsh-purge 的作者把开源版收缩为只允许回环与 RFC1918 地址。**安装一个技能，等于执行陌生人的提示词和脚本**——这个品类还没有安全模型。
- **钱进场了，而且都从“托管”切。** claude-mem 的安装器现在会引导登录、发 memory key、开 30 天试用；ECC 的私有仓库版 19 美元/席/月；Taste Skill 推出了桌面应用 TasteCode。开源部分留在 GitHub，收费部分落在托管、私有仓库和桌面壳上。
- **“全家桶”从新东西变成底盘。** superpowers 5,636、ECC 6,380、anthropics/skills 2,389，三个框架类仓库合计 30,590 星，占全榜 34.6%，但增速已经明显低于设计类技能。它们现在是入口，不是话题。
- **连续第二周，15 个位置里没有一个严格的非 AI 项目。** 星数还在通胀：Cloudflare 的技能自 9 月 14 日后没有任何提交，本周仍涨 11,908；karpathy-skills 4 月后停更，本周仍涨 4,277。

## AI 热门项目

### 1. [Nutlope/hallmark](https://github.com/Nutlope/hallmark)

- **它是做什么的**：给 Claude Code、Codex、Cursor、OpenCode 用的设计技能，由 Together AI 出品，目标是“拒绝看起来像 AI 生成的页面”。v2 的核心是把主题做成**材质**而不是模板：50 个主题，每个是一个不超过 8 KB 的文件加一张成品页截图，构建时只读一个；主题从不规定页面里有什么、按什么顺序排，所以同一个主题喂两个 prompt 会得到两张不同的页面。另外内置 755 张开放授权照片、按主题挑选并署名，能自己从 URL、dev server 或本地应用截取真实产品的图，还提供 `/hallmark redesign <path>`（重建但保留内容与接线）与 `/hallmark audit <path>`（只报告）。MIT，CSS 为主，2026 年 4 月创建。
- **为什么这周会热**：本周新增约 **1.21 万** stars，总 stars 约 **4.40 万**，2,321 个 fork。fork/star 只有 **5.3%**——这个比例说明用户形态是“装上就用”，不是“拿去改”。推力有两个：v2 是一次结构性大版本（50 主题、真实照片、redesign/audit、截自己的产品），以及 Together AI 的品牌背书。它在 Trending 页面上的渲染顺序也是第一。
- **有什么新意**：三级 gate 的划分比主题数量重要得多。**Floor 永不发布**：对比度、焦点态、reduced motion、编造事实、手机上排崩的布局。**Reflex 是模型默认会犯的毛病**，有理由可以推翻，但必须在记录里写明。**Finish 只是手艺细节，永远不阻塞上线。** 三档之间的区别是“谁能拍板”：机器、有理由的人、还是没人。再加一句 “A fresh-context reviewer gets the last word”——评审员从干净上下文进来，最后说话。**一个设计工具真正的产品决策，是告诉模型哪些事不许做，而不是给它更多词汇。**

### 2. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)

- **它是做什么的**：把 Cloudflare 内部漏洞挖掘流水线拆出来的开源审计技能。六个阶段：侦察（产出 `architecture.md` 与 `coverage-ledger.json`）、覆盖率驱动的猎捕（每个账本单位派独立 hunter，再用 critic 找缺口）、候选验证（每个候选项交给全新 verifier 去证伪）、结构化输出（`findings.json` 按 `report-schema.json` 校验）、独立记录复核、目标中立报告。多个 run 之间是累加的：用旧账本定位缺口，重验变更过的源码，不把过期或未解决的工作算成已覆盖。MIT，JavaScript，2026 年 6 月创建。
- **为什么这周会热**：本周新增约 **1.19 万** stars，总 stars 约 **5.55 万**，3,614 个 fork，108 个未关闭 issue。数字之外有个更值得注意的事实：**这个仓库最后一次推送是 9 月 14 日**，一个半月没有提交，本周仍拿到第二高的周增。它不是靠迭代上榜的，是被当成教材在传阅。
- **有什么新意**：本周它没有代码更新，但它提供的骨架在本周其他技能项目里反复出现——Hallmark 的“全新上下文评审员”、ECC 的 plan/review/verify 循环、Claude SEO 的并行 agent 分工，都是同构的：**产出必须结构化、验证者必须不是产出者、覆盖范围必须记账。** 一个停更六周的仓库还能站住第二，说明这个赛道当下稀缺的是流程，不是功能。

### 3. [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo)

- **它是做什么的**：Claude Code 里的 SEO 审计插件，26 个子技能 + 19 个专家 agent，最多 17 个 agent 并行扫一个站点，10 到 15 分钟出结果。覆盖面包括技术 SEO（抓取、索引、sitemap、robots、重定向、Core Web Vitals）、内容质量（E-E-A-T、薄页、主题覆盖）、结构化数据（发现、校验、写 Schema.org）、**AI 搜索可见性（GEO，判断 Google AI Overviews、AI Mode、ChatGPT、Perplexity、Gemini 引用你页面的概率）**、本地与电商 SEO、国际化站点，输出可导 PDF/Excel。MIT，Python，2026 年 2 月创建。
- **为什么这周会热**：本周新增约 **4,814** stars，总 stars 约 **2.51 万**，3,320 个 fork（13.2%），v2.5.0 于 10 月 22 日发布。它是本周“技能商品化”最彻底的一个样本：README 里有 `/seo` 命令演示 GIF、YouTube 完整演示、付费社区入口，还有一张自证页——用自己审计自己的站点，12 周 10.8K 次 Search Console 点击、移动端 PageSpeed 99。**在一个充满“我让我的网站涨了 300%”的品类里，给出可核对的 Search Console 截图，是相对诚实的做法。**
- **有什么新意**：两处细节比功能清单有价值。第一，**考核对象从“排名”变成“被引用”**：GEO 检查的是页面被 AI 搜索摘引的概率，这是 SEO 这个词在这两年真正发生的变化。第二，**按任务难度分配模型档位**：技术 SEO 用 Sonnet，内容编辑用 Opus，而不是全站都上最强模型。1077 个测试在这类技能项目里也少见——多数技能仓库连 CI 都没有。

### 4. [pbakaus/impeccable](https://github.com/pbakaus/impeccable)

- **它是做什么的**：给编码 agent 的“设计词汇表”。`npx impeccable install` 装上后，每个项目跑一次 `/impeccable init`，它会读代码、只问推断不出来的事（产品给谁用、要完成什么、有什么约束），写成 `PRODUCT.md`；`document` 把现有视觉系统记到 `DESIGN.md`。之后 24 个命令分四组：steer（bolder / quieter / distill / colorize / typeset / layout / animate / delight / overdrive）、review（critique 打分、audit 出 P0–P3 报告）、finish（polish / harden / clarify / adapt / optimize / onboard）、plan（shape / init / document / extract）。Apache-2.0，Rust CLI，2025 年 11 月创建，支持 20 多个 harness，README 里把 Hermes Agent 和 DeepSeek Harness 都列了。
- **为什么这周会热**：本周新增约 **1.20 万** stars，总 stars 约 **9.84 万**，5,808 个 fork，`cli-v4.8.0` 于 10 月 26 日发布。README 里那组对照图是本周传播力最强的素材：同一个模型（Fable 5.1）、同一份 brief（利古里亚海岸一间十四房的家庭旅馆），不带 Impeccable 得到“有品味的默认值”——奶油底、细衬线、斜体点缀、胶囊按钮；带上之后，页面围绕一张图展开：夜里从海面上看这栋房子。
- **有什么新意**：**它把形容词变成了“动词 + 对象”。** “Make it pop” 让模型去猜；`/impeccable bolder the pricing cards` 会加载专门为这一个动作写的 playbook，并且只作用于一个目标。更关键的是 `critique` 与 `audit` 的实现方式：**62 条确定性规则，无 LLM、无 API key**。也就是说“AI 味”被降解成了可以离线跑的静态检查——同一套思路在上周的 Cloudflare 校验器里已经出现过一次：**把判断权从模型手里拿走，交给可重复执行的程序。**

### 5. [obra/superpowers](https://github.com/obra/superpowers)

- **它是做什么的**：一套给编码 agent 的完整软件开发方法论：先不写代码，问清你到底要做什么；把 spec 切成短到能读完的块给你签字；然后生成一份“连热情但没品味、没判断力、没有项目上下文、还讨厌测试的初级工程师都能照着做”的实施计划，强调真红绿 TDD、YAGNI、DRY；你说 go 之后进入 subagent-driven development，agent 逐个任务推进并互相 review，经常能连续自主工作几小时而不偏离计划。MIT，Shell 为主，2025 年 10 月创建。
- **为什么这周会热**：本周新增约 **5,636** stars，总 stars 约 **31.01 万**（全榜最高），2.76 万 fork，v7.0.1 于 10 月 21 日发布。真实的推力是**分发位置**：它现在同时挂在 Anthropic 官方插件市场、OpenAI Codex 官方插件市场、Cursor 的 `/add-plugin`、Gemini CLI extensions、Devin CLI、Factory Droid、Antigravity、OpenCode、Qwen Code、Kimi Code，README 里连 Hermes Agent 的安装段落都单列了。
- **有什么新意**：那句对计划的验收标准其实是整套方法的核心：**计划的合格线是“最差的执行者也能照做”**，而不是“聪明人能看懂”。这是个和本周设计技能完全同构的动作——用约束替代判断力。当执行者的能力不可控时，唯一能提高下限的办法是把意图写死到不需要理解的程度。

### 6. [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)

- **它是做什么的**：一个 `CLAUDE.md` 文件，把 Karpathy 关于 LLM 编码毛病的观察整理成四条原则：**Think Before Coding**（显式陈述假设、给出多种解释、该反驳就反驳、糊涂了就停下问）、**Simplicity First**（能解决问题的极少代码，不做投机性设计）、**Surgical Changes**（不改你没读懂的代码、不做与任务正交的编辑）、**Goal-Driven Execution**（先写测试，成功标准必须可验证）。没有许可证字段，2026 年 1 月创建。
- **为什么这周会热**：本周新增约 **4,277** stars，总 stars 约 **22.76 万**，2.27 万 fork。但**最后一次推送是 4 月 20 日**——超过半年没有任何更新。22.7 万星的全部内容是一个 Markdown 文件，这是本周榜单通胀最极端的样本。
- **有什么新意**：本周没有新意可讲，它的价值在于提示一件结构性的事：**当一个仓库的全部内容是“给模型的一段纪律”，它的保质期由模型的默认行为决定**——模型改好一点，它就过时一点。四条原则里最耐用的是 Surgical Changes，因为它约束的是行为边界，而不是文风或偏好。

### 7. [TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents)

- **它是做什么的**：多 agent LLM 金融交易框架（[论文 arXiv:2412.20138](https://arxiv.org/abs/2412.20138)）：分析师团队、研究员多空辩论、交易员、风险管理分层协作，最后落到可回测的决策。Apache-2.0，Python，2024 年 12 月创建。
- **为什么这周会热**：本周新增约 **5,483** stars，总 stars 约 **11.91 万**，2.28 万 fork（19.1%），v0.7.1 于 10 月 27 日发布。它上榜不是故事驱动，而是版本节奏驱动：10 月连发 0.6.0、0.7.0、0.7.1，且三个版本都在修同一类问题。
- **有什么新意**：**这周的 changelog 是一份“如何不欺骗自己”的清单。** v0.7.1：决策只按收盘价结算、跨长假期正确结算、修掉“模型日期能读到运行日之后才提交的 filing”。v0.7.0：回测从每次决策后的第一个收盘开始计分；可以直接跑在你自己的 ChatGPT Plus/Pro 订阅上。更早的 0.5.x 则在铺 point-in-time 完整性——每个带日期的数据路径都只能看到当时已发布的内容。**在 Agent 满地跑的年份，金融类项目最值钱的工程资产不是模型，而是回测的诚实度。**（需要提醒：框架自带的回测口径再严，也不构成投资建议，历史回测与实盘之间隔着执行成本与滑点。）

### 8. [jakubkrehel/skills](https://github.com/jakubkrehel/skills)

- **它是做什么的**：一组做界面的 agent 技能，来源是作者的个人博客与设计工程杂志 Interfaces。八个技能各管一件事：`better-interface`（跨可访问性、布局、文案、排版、颜色、UI 打磨做一次评审，回一份排序报告）、`better-ui`（圆角、光学对齐、阴影、图标状态、动画的具体数值）、`better-typography`（字阶、字距、字体特性、换行、截断、标点）、`better-colors`（生成色板、命名语义 token、格式互转、测对比度）、`better-accessibility`（键盘与焦点、ARIA、可访问名称、表单、读屏播报、动效、缩放，对齐 WCAG 2.2）、`better-layout`、`better-writing`、`interface-review`。MIT，以 Markdown 为主，2026 年 7 月创建。
- **为什么这周会热**：本周新增约 **1,272** stars，总 stars 约 **9,642**，369 个 fork（3.8%），只有 10 个未关闭 issue——周增是全榜最低，但它几乎是最“干净”的一个。
- **有什么新意**：和动辄十几万星的设计技能相比，它的差异是**每一条都指向可验证的标准**：WCAG 2.2、对比度测量值、字阶与行高、光学对齐、截断与标点。没有主题墙、没有截图墙、也没有“品味”叙事。**当“品味”变成一个品类，最先被淘汰的是形容词，最后留下来的是标准。**

### 9. [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)

- **它是做什么的**：让编码 agent 做“有美术指导的页面”，而不是拼一张平均的落地页。三件事：给一个美术方向、找真实参考图、在真实浏览器里自查结果。用 `npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"` 安装，也可以作为 Claude Code 或 Codex 插件装。运行需要 Node 22+ 和一个已安装的 Chrome/Edge/Chromium，不需要 API key。MIT，JavaScript，2026 年 2 月创建，官网 tasteskill.dev。
- **为什么这周会热**：本周新增约 **4,975** stars，总 stars 约 **10.71 万**，7,246 个 fork，v2.1.5 于 10 月 24 日发布；本周同时上线了 **TasteCode**——把 Taste Skill 做成带内置设计 agent 的桌面应用，免费开源。从技能变成产品，是这周它拿到注意力的真正原因。
- **有什么新意**：**10.7 万星只对应 8 个未关闭 issue**，这个比例本身就说明了使用方式：装完就用，几乎不提需求。值得单独看的是“真实照片”：图库来自开放档案，按主题挑选并在页面上署名。**AI 味的最大来源不是排版，是素材——凭空生成的插图和头像。用真实素材替换生成素材，是“反 AI 味”里性价比最高的一招。**

### 10. [pingdotgg/t3code](https://github.com/pingdotgg/t3code)

- **它是做什么的**：一个“agent harness 控制台”。本机装着的 Claude Code、Codex、Cursor、Grok Build、OpenCode、Antigravity、fx，它都能接管，然后通过 iOS/Android 应用、Web、Electron 桌面端统一操作：远程访问、权限模式、多账号、MCP 让外部 agent 接进来、源码管理集成、后台服务 `t3 service install`。MIT，TypeScript，2026 年 2 月创建。

### 14. [YuJunZhiXue/dsh-purge](https://github.com/YuJunZhiXue/dsh-purge)

- **它是做什么的**：跑在本机已安装的官方 [DeepSeek Harness](https://www.deepseek.com/harness/) 上的红队插件。它做的不是“让模型回答”，而是把**宿主层拦截**与**模型拒绝**分开：harness 会在运行时改写 prompt、审批门、沙箱策略与会话迁移，所以只问“模型会不会答”会把宿主拦截误判成模型拒答。功能上是一个 dock（会话标题旁一个按钮，分 Clean / Drill 两页）：分组补丁状态、Apply/Restore/Uninstall、prompt 编辑器、多套规则集；启动时检查并重新应用，npm 覆盖 `node_modules` 之后不用手工改文件。Apache-2.0，JavaScript，2026 年 8 月创建，v1.1.86 于 10 月 31 日发布。

- **有什么新意**：这周它自己成了新闻。README 里作者写道，有人把这份开源作品公开拿去卖，之后“作者被叫去谈话”，于是他做了三件事：**开源版只允许本地实验网络**——只放行回环与 RFC1918，域名（含 hosts）先解析再校验，任何公网应答或解析失败一律拦截；**禁止游戏作弊用途**（aimbot、wallhack、对游戏改内存、反作弊绕过，prompt 和会话门都会拦）；**要求署名**，二开必须注明来源。**一个工具从“能干什么”退回“允许干什么”，通常不是因为技术，而是因为滥用与法律。**

## 非 AI / 泛基础设施

**本周严格与 AI 无关的项目是 0 个，连续第二周。** 15 个仓库里：5 个是设计向技能，5 个是技能框架与技能目录（superpowers、ECC、anthropics/skills、karpathy-skills、Cloudflare 审计技能），2 个是记忆与控制台（claude-mem、T3 Code），1 个是金融多 agent 框架（TradingAgents），1 个是宿主红队插件（dsh-purge），1 个是 IM 机器人平台（AstrBot）。没有推理引擎、没有数据库、没有编译器，连一个“贴着系统底层”的边缘项目都没有。

#### 为什么这周仍然一个都没有

上周的零非 AI 可以用“平台方同一周发布官方目录”解释，这周的解释不同：**新增的注意力几乎全部被一个细分品类吸走**。设计向技能一周内冒出五个（Hallmark v2、Impeccable v4.8、Taste Skill v2.1.5 + TasteCode、jakubkrehel/skills、Claude SEO v2.5），加上框架类三个稳定占位、记忆与控制台各两个，15 个位置就满了。非 AI 项目不是不活跃，而是这一周没有任何一个拿到了能进前 15 的周增。

这也提醒一件事：**15 是榜单的容量，不是世界的容量。** 同一天不同时刻抓取，Trending 返回的组合会变化（本次两次抓取得到了不同名单与不同排序，其中一次出现了 `php/php-src` 这类项目，周增 960）。把这份榜单当“本周 Agent 工具链的供给清单”是准确的，当“技术趋势全貌”就会失真。

## 技术趋势分析

**一、“品味”正在被工程化成门槛，而不是被模型学会。** Hallmark 的三级 gate、Impeccable 的 62 条确定性规则、jakubkrehel 的 WCAG 对齐，共同点是：不指望模型“变得有审美”，而是把不可接受的结果列成清单，让机器去拒。这和上周 Cloudflare 的覆盖率账本、三态结论是同一条路线——**判断力被外置成规则，模型只负责在规则内发挥。** 这条路线的好处是可审计、可回归；坏处是它会把产物往“合规的平均值”收敛。

**二、反 AI 味的第一步是换素材，不是换排版。** 本周三个头部项目都在这件事上下了重注：Hallmark 内置 755 张授权照片并署名、Taste Skill 从开放档案里找真实参考图、Impeccable 拿同一模型跑对照图证明差异。原因很实际——**排版是可以被规则修正的，编造的配图和事实不能**。Hallmark 把“编造事实”直接放进永不发布的 Floor，也是同一个判断。

**三、技能的分发渠道已经收敛，竞争转到维护能力。** superpowers 进了 Anthropic 与 OpenAI 两家的官方市场，ECC 走 GitHub App + npm，anthropics/skills 是示范仓库。格式之争（`SKILL.md` + 插件清单）基本结束，剩下比的是版本节奏、兼容矩阵和 issue 处理速度。ECC 那张 platform support matrix 值得当成这类文档的范本：**明确写出哪些宿主是原生、哪些只是能力受限的适配，比宣称“支持 20 个工具”有用。**

**四、供应链与合法性风险第一次成为项目首页的内容。** ECC 的防伪警告、dsh-purge 的网络限制与署名要求、claude-mem 的托管默认值，三件事指向同一个事实：**技能是可执行内容，装一个技能等于执行陌生人的提示词和脚本。** 而这个品类目前既没有签名机制，也没有权限模型——本周只有一个项目（Cloudflare 的技能）要求“没有 OS 级沙箱就不执行”。

**五、钱从“托管”和“壳”切入，开源部分继续留在 GitHub。** claude-mem 卖托管记忆（30 天试用后回落到自带额度）、ECC 卖私有仓库版（19 美元/席/月）、Taste Skill 推出桌面应用 TasteCode、Claude SEO 引流到付费社区。模式高度一致：**核心逻辑 MIT/Apache 开源换分发，收费落在托管、私有仓库、桌面壳和报告交付上。** 这大概是 Agent 工具在 2026 年找到的第一个可持续结构。

**六、星数继续通胀，需要用三个指标校正。** 本周三组数字足够说明问题：T3 Code 3,885 个 issue 对 3.58 万星（高期待、早公开）；Taste Skill 8 个 issue 对 10.71 万星（装完就用，几乎不参与）；Cloudflare 停更六周仍涨 1.19 万（内容型仓库的生命周期与代码仓库不同）。判断方式不变：**周增看注意力，issue 与提交看维护压力，最后一次推送看项目是否还活着。**

## 本周最值得关注的新鲜点

- **Hallmark 的三级 gate**：Floor 永不发布、Reflex 可按记录推翻、Finish 永不阻塞。三档的区别是“谁有权拍板”，这个划分可以直接搬到任何 agent 产出物上。
- **Impeccable 的 62 条确定性规则**：零 LLM、零 API key，把“AI 味”变成可离线执行的静态检查。这是本周最容易被低估的工程决策。
- **TradingAgents v0.7.1 的评测口径**：只按收盘结算、跨长假期结算、禁止读到运行日之后才提交的 filing。把 look-ahead bias 当版本主题来修，比加十个 agent 更有价值。
- **claude-mem 的隐私默认值翻转**：托管观察者成为默认路径，本地观察者需要显式 `--provider host`。记忆层的商业模式跑通了，但默认值的含义变了。
- **ECC 的首页防伪声明**：29 万星的项目要求用户只从官方渠道安装，因为第三方镜像可能带恶意软件。技能供应链的安全问题已经从论文变成 README 第一屏。
- **superpowers 对计划的验收标准**：“连没品味、没判断力、没上下文、还讨厌测试的初级工程师都能照着做”。这句自嘲其实是整套方法论的合格线。

## 结语

这一周的两个方向，其实是同一件事的两面：**向外是品味，向内是出处。** 前者要解决“为什么我的页面看起来像批量生成的”，后者要解决“这个技能是谁写的、能不能装、以后收不收费”。

两边都没有靠“模型更强”来解决。Hallmark 靠拒绝，Impeccable 靠 62 条能跑的规则，jakubkrehel 靠 WCAG，claude-seo 靠 Search Console 截图，TradingAgents 靠改评测口径，ECC 靠一句防伪警告。**当执行变得廉价，可信和好看就成了唯一还稀缺的东西——而这两样都不能靠许愿得到，只能靠约束、素材和审计。**

连续两周零非 AI 项目这件事，也不必读成“开源只剩 AI”。更准确的说法是：这一周供给侧的注意力被一个具体品类（设计技能）和一种焦虑（技能供应链）占满了，而基础设施项目正好处在版本空窗。榜单是注意力的快照，下周它很可能又换一副面孔。
