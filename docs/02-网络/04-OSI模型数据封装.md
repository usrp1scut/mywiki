# OSI 模型各层的数据封装名称

数据从上往下传递时，每一层都会加上本层的头部（封装），不同层的数据单元有各自的名称。

| 层级 | 数据单元 | 英文 |
|---|---|---|
| 传输层 | 段 | Segment |
| 网络层 | 包 / 分组 | Packet |
| 数据链路层 | 帧 | Frame |
| 物理层 | 比特流 | Bit / Bit stream |

补充说明：

- 应用层、表示层、会话层的数据通常统称为**数据（Data）**。
- 封装是逐层进行的：上层数据 + 本层头部，交给下一层继续处理。
- 接收端方向相反，逐层剥离头部（解封装），还原出原始数据。
