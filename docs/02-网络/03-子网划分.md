# 子网划分：概念、计算与作用

## 是什么

子网划分（Subnetting）是把一个较大的 IP 网络拆成多个较小网络（子网）的技术。

做法是**从主机位中借出若干位作为子网位**，再由子网掩码区分哪部分是网络/子网标识，哪部分是主机标识。

## 示例：把 192.168.1.0/24 拆成 /26

掩码从 `/24` 改为 `/26`（借用 2 位主机位），一个网段被拆成 4 个子网：

| 子网 | 网络地址 | 可用主机范围 | 广播地址 |
|---|---|---|---|
| 1 | 192.168.1.0/26 | .1 ~ .62 | .63 |
| 2 | 192.168.1.64/26 | .65 ~ .126 | .127 |
| 3 | 192.168.1.128/26 | .129 ~ .190 | .191 |
| 4 | 192.168.1.192/26 | .193 ~ .254 | .255 |

每个子网有 64 个地址，可用主机 62 个（扣除网络地址和广播地址）。

## 计算公式

```text
子网数量       = 2^n        （n = 借用的主机位数）
每个子网可用主机数 = 2^h - 2    （h = 剩余主机位数）
```

## 为什么要划分子网

1. **缩小广播域，提升网络性能**：广播报文只在本子网内传播，减少带宽占用和设备性能损耗。
2. **提高安全性**：子网之间的通信必须经过路由器或三层交换机，可以在此用 ACL、防火墙做访问控制，例如隔离财务部、访客网络和服务器区。
3. **节省 IP 地址**：给只有 2 台设备的点对点链路分配一整个 `/24` 会浪费 250 多个地址，改用 `/30`、`/31` 可按需分配。
4. **便于管理和故障排查**：按部门、楼层、功能或地理位置划分，结构清晰，出问题时更容易定位范围。
5. **适应不同物理网络**：不同的局域网、广域网链路本来就需要不同网段，子网划分让一个大地址块能灵活分配。
6. **提高路由效率**：合理规划的子网可以配合路由汇总，减小路由表规模。

## 延伸

- **VLSM（可变长子网掩码）**：同一个主网内，针对不同规模的网段使用不同长度的掩码，进一步减少浪费。
- **CIDR**：用前缀长度表示网络，替代传统的 A/B/C 类划分，是路由汇总的基础。
