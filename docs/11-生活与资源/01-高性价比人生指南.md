# 高性价比人生指南（导读）

《高性价比人生指南》（HowToLiveBetter）是由 [eternity4719](https://github.com/eternity4719) 发起、与项目贡献者共同维护的生活资料集。它围绕健康、时间与精力、金钱、人身自由整理常见问题，把日常习惯、就医、劳动权益、家庭照护、消费与技术从业等主题放在同一套查阅目录中。每个条目尝试交代需要投入的成本、预期收益、适用条件和资料出处，适合带着一个具体问题查找线索。

**本站收录的是导读，未导入全文。** 你可以在这里阅读内容简介、理解条目的组织方式、选择章节；下方全部章节链接均为 **GitHub 外链**，打开后离开本 wiki。收录时上游有 34 章、765 条建议，正文约 2.36 MB，已超过本仓库原有 Markdown 笔记总量的四倍，因此沿用本站的资源导读方式，暂不镜像整本书及其大量核实记录。

## 怎样使用这份资料 {#reading}

先找与你眼前问题有关的一章，再回到原条目查看限制条件和引用出处。原书把建议视为可选资料，不要求读者逐条执行；章节中的“划算”也不能替代个人的偏好、处境和判断。

阅读时可以依次看四件事：

1. **适用对象**：研究或规则针对哪些人、哪个地区、哪个时间段，是否与你的情况相符。
2. **成本与收益**：钱、时间、精力和执行难度分别是多少，换回的是健康、节省开支、时间还是法律保障。上游不把这些不同类型的收益折算成同一个数。
3. **证据与限制**：打开原条目的文献或官方文件，继续读备注、争议和待核实标记，避免只看一句结论或百分比。
4. **当前有效性**：特别核对政策截止日期、待遇条件、医学适用人群和来源是否更新。固定版本方便追溯，但不会自动反映后续修订。

上游的证据分级可这样读；这是对其自定义分级的概述，并非本站作出的质量认证：

| 上游标记 | 阅读时应理解的含义 |
| --- | --- |
| A | 有可追溯的具体数字及研究来源；法律政策条目则可能表示引用了法条或官方原文。观察性研究也可能被列为 A，不能据此认定因果关系或当前仍然适用。 |
| B | 有研究支持，但可能缺少可确定的数值，或只由单项、小样本研究支持。 |
| C | 作者经验或惯常做法，缺少直接研究支持。 |
| 争议／待核实 | 需要连同反方证据、备注或尚未核实之处一起读，不能当作已经确认的结论。 |

“性价比”是上游另行作出的判断，与证据等级不同。收益栏里的相对风险变化也不等于每一百个人减少多少事件；应回到原文核对研究对象和原始风险。详见[收录版本的 README（外链）](https://github.com/eternity4719/HowToLiveBetter/blob/3f59f98be11305902681a8f20ed073c4c4588eee/README.md)。
