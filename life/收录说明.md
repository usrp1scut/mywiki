1. **完整保留正文。** 不改写原文建议、统计数字、来源链接、免责声明、争议、待核实标记及日期。原文提到广告、赞赏或诈骗的讨论属于正文，不因出现这些词语而删除。

4. **区分站内与外部资料。** 已收录的章节、条目和总目录使用站内链接；原始文献链接保持原样。未镜像的 `docs/` 拓展长文改为带固定提交的 GitHub 链接，标注“上游外链”。CC BY 4.0 指向本站保留的许可全文；MIT 代码许可仍为上游外链。

## 可复现的完整性检查

仓库 `life/_meta/upstream.json` 记录固定提交及每个输入文件的 Git blob SHA、SHA-256 和字节数；`life/_meta/import-report.json` 记录各章条目数、转换后的正文哈希和链接处理结果。

本站编写的导入脚本只读取上述清单中的正文、README 与许可证。下面的命令下载固定来源并生成本站章节，不会执行上游脚本或安装上游 skill：

```bash
python3 scripts/import-life-guide.py --source-dir /tmp/howtolivebetter --fetch
python3 scripts/import-life-guide.py --source-dir /tmp/howtolivebetter --check
yarn build
node scripts/check-life-guide.mjs
```

检查会核对所有输入哈希、34 章及 767 个连续条目，将允许的链接和锚点修改还原后与原文逐字节比较，再核对生成文件、许可证副本、站内路由、条目锚点、侧栏和前后章链接。外部文献保留原始链接，不承诺其长期可访问。

后续同步应重新核对上游许可、正文和风险提示，更新来源清单、导入日期和改动记录后再执行导入与构建检查。发现正文问题可先核对上游修订，避免悄悄改写固定版本。

## 自动更新

仓库每天北京时间 **07:23** 检查上游默认分支；GitHub 调度可能延迟。正文或收录依据有变化时，同步脚本更新章节、条目数、目录、署名和版本记录，通过完整性检查、站点构建及链接检查后提交到 `main` 并自动发布。没有相关变化时不产生提交或部署。

自动检查只处理上游文字数据，不执行上游代码或安装 skill。许可证全文、README 的许可声明、章节路径或正文格式发生不兼容变化，以及正文出现可识别广告区块时，同步会失败并保留当前版本，等待维护者检查。医学、法律和财务内容的更新仍是上游作者的修订，不代表本站重新作了专业审查。

当前版本以本页记录为准；每次更新均可通过仓库提交历史追溯。[查看自动更新运行记录（外链）](https://github.com/usrp1scut/mywiki/actions/workflows/sync-life-guide.yml)。维护者可在该页面手动运行检查；失败详情和重试也在 GitHub Actions 中处理。
