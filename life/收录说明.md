## 可复现的完整性检查

仓库 `life/_meta/upstream.json` 记录固定提交及每个输入文件的 Git blob SHA、SHA-256 和字节数；`life/_meta/import-report.json` 记录各章条目数、转换后的正文哈希和链接处理结果。

本站编写的导入脚本只读取上述清单中的正文、README 与许可证。下面的命令下载固定来源并生成本站章节，不会执行上游脚本或安装上游 skill：

```bash
python3 scripts/import-life-guide.py --source-dir /tmp/howtolivebetter --fetch
python3 scripts/import-life-guide.py --source-dir /tmp/howtolivebetter --check
yarn build
node scripts/check-life-guide.mjs
```
